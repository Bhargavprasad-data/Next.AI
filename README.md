# Next.AI — Static Site Scaffold

This is a minimal, accessible static website scaffold. It includes a simple responsive layout, semantic HTML, and light JavaScript for small enhancements.

Files
- `index.html` — Home page
- `about.html` — About page
- `contact.html` — Contact page with a basic mailto form
- `css/styles.css` — Site styles
- `js/main.js` — Tiny JS for footer year and minimal form validation

Preview locally
1. Open `index.html` in a browser, or
2. Use VS Code Live Server extension and open the workspace root.

Deploy
- GitHub Pages: push the repo to GitHub and enable Pages from the `main` branch (root).
- Netlify/Vercel: drag-and-drop the folder or connect the repo.

Next steps
